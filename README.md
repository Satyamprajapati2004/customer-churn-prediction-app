# 🚀 Telecom Customer Churn Prediction App

Aapka ye project ek **End-to-End Machine Learning Solution** hai jo telecom customers ke behavior ko analyze karke batata hai ki wo service chhodenge (Churn) ya nahi.

## 📊 Project Overview
Is project mein humne Machine Learning ka istemal kiya hai taaki business ko pehle se pata chal sake ki kaunse customers dissatisfied hain. Isse company unhe rokne ke liye sahi offers de sakti hai.

## 🛠️ Tech Stack Used
* **Language:** Python
* **Libraries:** Pandas, Scikit-learn, NumPy
* **Web Framework:** Streamlit (UI ke liye)
* **Deployment:** Streamlit Cloud
* **Version Control:** Git & GitHub

## ✨ Key Features
* **Real-time Prediction:** User se data lekar turant result dikhata hai.
* **Interactive UI:** Simple sliders aur input boxes ka istemal.
* **Cloud Hosted:** Ye app kahin se bhi access ki ja sakti hai.

## 📂 Project Structure
* `churn_app.py`: Main Python script jo UI aur Model logic sambhalti hai.
* `WA_Fn-UseC_-Telco-Customer-Churn.csv`: Dataset jiska use model training ke liye hua.
* `requirements.txt`: Libraries ki list jo app ko chalane ke liye zaroori hai.

## 🛠️ How to run locally
1. Clone the repo: `git clone https://github.com/saaa637/customer-churn-prediction-app.git`
2. Install requirements: `pip install -r requirements.txt`
3. Run app: `streamlit run churn_app.py`
